# QR Code Generator 

This is a simple QR Code Generator built using only HTML, CSS, and JavaScript in one single file. It uses the open-source QRCode.js library to generate QR codes instantly in the browser.

## ✅ Features

- Generate QR code from text or URL
- No installation required
- Responsive and clean design
- Fully contained in one HTML file

## 📦 How to Use

1. Download or copy the `index.html` file.
2. Double-click to open it in your browser.
3. Enter your text or URL in the input box.
4. Click the **"Generate QR Code"** button.
5. Your QR code will appear below.

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- [QRCode.js](https://github.com/davidshimjs/qrcodejs)
